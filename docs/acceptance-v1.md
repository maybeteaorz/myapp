## 执行过程中发现并修复的缺陷（均已回归）

| 编号 | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| BUG-1 | 自动保存 350ms 防抖窗口内刷新/关闭页面，改动丢失 | 违反 PRD 1.1"关掉不丢一个字" | `core.js` 增加 `pagehide` 时 `sendBeacon` 补偿保存 |
| BUG-2 | 勾选备忘后"N 条未处理"计数不更新 | 首页显示错误 | `home.js` 抽出 `paintHint`，勾选/删除后同步刷新 |
| BUG-3 | 删除项目后编辑弹窗滞留（`onMount` 未接收 `close`） | 已删项目仍挂着编辑表单 | `dev.js` 补 `close()` |
| BUG-4 | 首页勾选计划后圆环与条幅不更新（PRD 6.5 登记） | 需刷新才一致 | `home.js` `paintHomePlan` 三处同步 |

## 遗留说明（非缺陷）

- B5"重启电脑"、C5"连续两天"采用等效验证；首次自然重启/隔日使用时顺手看一眼即可。
- G5 复制验证的是"传给剪贴板 API 的内容正确"；无头环境无法人工粘贴，日常使用第一次复制时留意一下。
