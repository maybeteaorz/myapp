# 个人工作生活台

一个人的本地工作台：把工作（开发、咨询）、表达（自媒体）、身体（健身、饮食）、生活（娱乐）放在同一个界面。**一台电脑、一个浏览器、一份文件。** 不登录、不联网、不上传。

## 怎么用

1. 双击文件夹里的 `启动.bat`
2. 浏览器自动打开 `http://127.0.0.1:5188`
3. 用完关掉那个黑色窗口就停了，数据已经随时保存

服务只监听本机 127.0.0.1，局域网内其他设备访问不到。端口被占用时自动换 5189、5190……最多尝试 10 次。

## 数据在哪、怎么不丢

| 项 | 说明 |
|---|---|
| 数据文件 | `data\data.json`（UTF-8 JSON，记事本可直接打开看） |
| 自动保存 | 任何改动后 350ms 内自动落盘，无保存按钮；页面刷新/关闭瞬间未落盘的改动会立即补写 |
| 每日快照 | 每天首次保存时把前一天的数据留一份到 `data\backups\data-日期.json`，最多保留 40 份 |
| 导出备份 | 「数据与设置」页右上角"导出备份"，得到一个 json 文件 |
| 恢复备份 | 「数据与设置」页备份列表点"恢复"；恢复前自动留一份 `before-restore_*` 底 |
| 换电脑 | 把整个 `app` 文件夹拷走即可（新电脑需装 Node.js），或导出 json 后在新电脑导入 |

## 九个模块

- **首页总览** — 问候 + 今日完成度 + 六格摘要 + 今日时间轴 + 快速备忘；其他模块今天到期的事自动汇入
- **今日计划** — 按"几点做什么"排时间线；其他模块今天的事在底部只读汇总
- **自媒体** — 选题 → 写作中 → 待发布 → 已发布 四列看板
- **开发工作** — 按项目管任务 / bug / 代码备忘
- **咨询工作** — 客户档案、沟通纪要、待跟进（到日子自动汇入今日计划）
- **健身计划** — 训练模板一键开练、逐动作打卡、体重趋势、连续打卡
- **饮食计划** — 食物库按份记、热量与三大营养素自动累加、点格子记水
- **游戏娱乐** — 在玩/想玩/通关/弃坑、+30 分记时长、本周柱图
- **数据与设置** — 称呼与目标、备份恢复、数据概览、清空

快捷键：`Alt + 1~9` 直接跳模块。

## 常见问题

- **打开是"读不到数据"**：启动窗口被关了。重新双击 `启动.bat`，再刷新页面。
- **左下角显示"保存失败"**：服务没在运行。确认黑窗口还开着。
- **想改数据文件**：可以，改前先在设置页导出一份备份；文件是标准 JSON，改坏结构会用备份恢复。
- **两个窗口同时改数据**：后保存的会覆盖先保存的，日常请只开一个窗口。

## 开发与测试（改代码时才需要）

```bash
node server.js                 # 启动（NO_OPEN=1 不自动开浏览器）
bash tools/check.sh            # 全量语法检查
node tools/run-tests.js all    # 全部自动化测试（真实浏览器逐条验收）
node tools/run-tests.js phase1 # 只跑阶段1用例
bash tools/screenshot.sh       # 九个页面截图到 tools/shots/
```

- 需要本机装有 Node.js（≥ 22，自带 WebSocket）和 Edge/Chrome
- 零依赖：无 package.json、无构建步骤，前端为原生 JS
- 需求与验收标准见 `PRD.md`，执行计划见 `DEV-PLAN.md`，验收记录见 `docs/acceptance-v1.md`
