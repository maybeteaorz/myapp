# 个人工作生活台

一个人的本地工作台：把工作（开发、咨询）、表达（自媒体）、身体（健身、饮食）、生活（娱乐）放在同一个界面。**一台电脑、一个浏览器、一份文件。** 不登录、不联网、不上传。

## 1. 解决什么问题

工作和生活的记录散落在待办 App、表格、备忘录里，互相看不到，还担心云端隐私。这个项目把它们收进一个只在你电脑上运行的界面，目标是三条：

- **10 秒知道今天该干嘛**——打开首页就有答案，不用翻
- **记录成本够低**——大多数记录是一次点击 + 一行字，改动即时生效
- **数据绝对不丢**——存在本机文件里，刷新、关机、重启都不受影响，且有每日快照兜底

## 2. 主要功能

| 模块 | 功能 |
|---|---|
| 首页总览 | 问候 + 今日完成度圆环 + 六格摘要（各模块今天的要点）+ 今日时间轴 + 快速备忘；其他模块今天到期的事自动汇入 |
| 今日计划 | 按"几点做什么"排时间线，带标签/优先级/勾选，可翻历史；其他模块今天的事在底部只读汇总 |
| 自媒体 | 选题 → 写作中 → 待发布 → 已发布 四列看板；记录平台/正文/发布时间/阅读点赞评论；**发布数据柱状图**（最近 12 篇，阅读/点赞/评论切换，点柱子直接编辑） |
| 开发工作 | 按项目分，每个项目有 任务看板 / Bug 表 / 代码备忘（一键复制）三个页签；页签右侧有醒目的"新增"主按钮 |
| 咨询工作 | 客户档案、沟通纪要时间线、待跟进提醒（到日子自动汇入今日计划）、本月工时收入统计；客户可删除（连带沟通记录，二次确认） |
| 健身计划 | 训练模板一键开练、逐动作打卡改重量、体重趋势折线、连续打卡；**月历视图**显示每天练了什么部位/动作/组数/重量 |
| 饮食计划 | 常用食物库按份记，热量与三大营养素自动累加，点格子记水；**月历视图**显示每天热量（目标内标绿、超标标红） |
| 游戏娱乐 | 在玩/想玩/通关/弃坑 分组，"+30 分 / +1 小时"记时长，本周时长柱状图 |
| 数据与设置 | 称呼与目标设置、数据概览、备份导出/导入、从历史快照恢复、清空重置（双重确认） |

通用能力：

- **自动保存 + 手动保存**：任何改动 350ms 内自动落盘；左下角保存按钮和 `Ctrl + S` 可立即写盘
- **快捷键**：`Alt + 1~9` 直接跳模块
- **页面内提醒**：内容到期、客户该跟进等在首页/计划页汇总显示（不做系统弹窗）

## 3. 安装方法

无需安装包、无依赖、无构建步骤，只需要电脑上有 **Node.js**（建议 ≥ 22，用来跑本地服务）。

1. 把整个 `app` 文件夹放到任意位置（例如 `D:\！学习用\app`）
2. 双击文件夹里的 **`启动.bat`**
3. 浏览器自动打开 `http://127.0.0.1:5188`，即装即用

首次启动后 `data\data.json` 会自动生成。服务只监听本机 127.0.0.1，局域网内其他设备访问不到；端口被占用时自动换 5189、5190……最多尝试 10 次。

## 4. 使用方法

**日常使用（三步）**：

1. 双击 `启动.bat`，浏览器自动打开界面
2. 在各模块记录；所有改动自动保存（也可点左下角按钮或 `Ctrl + S` 手动保存）
3. 用完直接关掉浏览器和那个黑色窗口，数据已落盘

**各模块典型操作**：

- 今日计划 / 首页备忘：输入框敲一行字按回车即存，可连输多条；点文字可改，勾掉只是完成不删除
- 自媒体：卡片上直接点"开始写 / 写完了 / 已发布"推进状态；点卡片填正文草稿和数据表现
- 开发工作：先建项目，再用页签旁的绿色按钮加任务 / 记 bug / 存代码备忘
- 咨询工作：记一次沟通后可设"下次跟进日期"，到期自动出现在今日计划和首页
- 健身：从模板"开练"后逐个动作勾完成；日历点某天看当天动作明细
- 饮食：从食物库选食物填份数，热量自动相乘；点水格加减
- 备份恢复：「数据与设置」页导出 json 或从历史快照恢复（恢复前自动留底）

**数据安全**：

| 项 | 说明 |
|---|---|
| 数据文件 | `data\data.json`（UTF-8 JSON，记事本可直接打开） |
| 每日快照 | 每天首次保存时留一份到 `data\backups\data-日期.json`，最多 40 份 |
| 换电脑 | 拷走整个 `app` 文件夹（新电脑需装 Node.js），或导出 json 后导入 |

常见问题：打开"读不到数据"→ 启动窗口被关了，重新双击 `启动.bat`；左下角"保存失败"→ 服务没在运行；两个窗口同时改数据 → 后保存的覆盖先保存的，请只开一个窗口。

## 5. 输入输出示例

**例 1：排一条今日计划**

- 输入：在「今日计划」页输入框输入 `09:30 写周报`，回车
- 输出：时间线出现一条 09:30 的待办（可再设标签和优先级），左下角显示"已保存 09:31"，`data\data.json` 中写入：

```json
"plan": {
  "2026-11-18": [
    { "id": "p1", "text": "写周报", "start": "09:30", "tag": "工作", "prio": 1, "done": false }
  ]
}
```

**例 2：记一餐**

- 输入：在「饮食计划」页从食物库选"鸡胸肉"、份数 1，加入午餐
- 输出：当日热量条自动累加 165 kcal、蛋白质 31 g；若超过目标（默认 2000），热量条变红：

```json
"logs": {
  "2026-11-18": {
    "lunch": [
      { "id": "e1", "name": "鸡胸肉", "qty": 1, "unit": "份", "kcal": 165, "protein": 31, "carb": 0, "fat": 3.6 }
    ],
    "water": 5
  }
}
```

**例 3：内容发布后看数据**

- 输入：把一篇内容推进到"已发布"，填阅读 4500 / 点赞 380 / 评论 66
- 输出：「自媒体」页"发布数据"柱状图中多出一根柱子，悬停显示标题与三项数据，点柱子可回编辑

**例 4：手动保存**

- 输入：任意改动后按 `Ctrl + S`（或点左下角保存按钮）
- 输出：状态区立即显示"已保存 16:43"，数据同步写入 `data\data.json`

## 开发与测试（改代码时才需要）

```bash
node server.js                 # 启动（NO_OPEN=1 不自动开浏览器）
bash tools/check.sh            # 全量语法检查
node tools/run-tests.js all    # 全部自动化测试（真实浏览器逐条验收）
node tools/run-tests.js phase1 # 只跑阶段1用例
bash tools/screenshot.sh       # 九个页面截图到 tools/shots/
```

- 需要本机装有 Node.js（≥ 22，自带 WebSocket）和 Edge/Chrome
- 零依赖：无 package.json、无构建步骤，前端为原生 JS
- 需求与验收标准见 `PRD.md`，执行计划见 `DEV-PLAN.md`，验收记录见 `docs/acceptance-v1.md`
